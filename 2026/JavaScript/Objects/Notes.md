## Key Learnings

- Objects store data in key-value pairs.
- Values can be accessed using dot notation and bracket notation.
- Properties can be added and updated dynamically.
- Objects can be nested inside other objects.
- Arrays can contain multiple objects.
- Math object provides useful mathematical methods.
- Random numbers can be generated using Math.random().
