## Key Learnings

### Objects
- Objects store data in key-value pairs.
- Data can be accessed using dot notation and bracket notation.
- Existing properties can be updated and new properties can be added dynamically.

### Nested Objects
- Objects can contain other objects.
- Useful for representing complex data structures.

#Array of Objects
- Multiple objects can be stored inside an array.
- Commonly used for users, products, posts, etc.

- Math.pow()
